5. Convertir el numero 254,125 de decimal a formato IEEE754, indicando los pasos utilizados para calcular:

a) Signo
b) Exponente
c) Mantisa

Vamos a utilizar para 32 bits (simple precisión)

a) Signo: 1 bit (bit 31)
b) Exponente: 8 bits (bit 30 a 23)
c) Mantisa: 23 bits (bit 22 a 0)

a) El signo es 0 ya que es positivo

b) Para calcular el exponente se debe pasar la parte entera a binario:

254 = 11111110

Luego pasar la parte fraccionaria a binario:

,001

el numero entero mover la coma hasta el 1 más significativo:

1,1111110001 x 2^7 

El exponente conseguido se le debe sumar 127 y se consigue 134, pasandolo a binario nos queda:

134 = 10000110

Este es el valor de Exponente = 10000110

c) La mantisa son todos los valores despues del '1,' y se los completa con 0 hasta los 23 bits:

11111100010000000000000

0 10000110 11111100010000000000000
